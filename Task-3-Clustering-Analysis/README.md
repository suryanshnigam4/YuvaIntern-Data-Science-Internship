
# Task 3 – Unsupervised Learning and Customer Segmentation

## Objective

Perform customer segmentation using unsupervised learning techniques on the Online Retail dataset.

## Approach

Customer segmentation was performed using RFM (Recency, Frequency, Monetary) analysis followed by K-Means clustering.

### RFM Features

- Recency – Number of days since the customer's last purchase
- Frequency – Number of unique invoices associated with the customer
- Monetary – Total transaction value generated by the customer

## Methodology

1. Loaded the cleaned Online Retail dataset.
2. Created customer-level RFM features.
3. Applied log transformation to reduce skewness.
4. Standardized the clustering features using StandardScaler.
5. Evaluated K-Means models for K = 2 to 10.
6. Used the Elbow Method and Silhouette Score to evaluate cluster choices.
7. Selected K = 2 based on the highest silhouette score.
8. Applied final K-Means clustering.
9. Used PCA for two-dimensional cluster visualization.
10. Analyzed cluster characteristics using Recency, Frequency, and Monetary metrics.

## Results

| Cluster | Customers | Avg Recency | Avg Frequency | Avg Monetary |
|---|---:|---:|---:|---:|
| Cluster 0 | 2,672 | 134.09 | 1.67 | £495.59 |
| Cluster 1 | 1,666 | 25.89 | 8.44 | £4,539.60 |

### Model Evaluation

- Algorithm: K-Means
- Number of clusters: 2
- Silhouette Score: 0.4328
- Customers segmented: 4,338
- Features: Recency, Frequency, Monetary

## Cluster Interpretation

### Cluster 0 – Low-Engagement Customers

Customers in this group generally have higher recency, lower purchase frequency, and lower monetary value.

### Cluster 1 – High-Engagement Customers

Customers in this group generally purchase more frequently, have more recent purchases, and generate higher transaction value.

## Business Implications

The segmentation can support customer retention, targeted promotions, personalized recommendations, and customer re-engagement strategies.
